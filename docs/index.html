Quickstart

Deployment & Execution Manual

1

Execute the Local Compilation

Build and package the production installer dynamically. Run the packaging command from the repository root:

npm run build
2

Locate Setup Package

The secure executable will be generated inside the local releases directory:

.\release\0.0.0\SmartCursorX-Windows-0.0.0-Setup.exe
3

Publish GitHub Release

Simply push your commits to GitHub and upload your generated executable `.exe` as a release asset in a release tagged `v1.0.0`. The download link on this page will instantly activate.
