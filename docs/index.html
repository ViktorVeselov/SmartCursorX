Functional Features & Operations

Security Workspace Path Containment

Validates and confines all code generation, search, and reading activities within the resolved active workspace directory path. Path traversal queries utilizing relative indicators (e.g., ../) are detected and blocked at the Electron IPC execution boundary.

AI Engine Pluggable Provider Support

Integrates standard cloud providers alongside local interfaces and custom OpenAI-compatible proxies:

  • OpenAI & Anthropic: Secure key registration and streaming chat integration.
  • Ollama (Local): Fully local model routing (e.g., Llama 3, Mistral) without external network dependencies.
  • OpenRouter.ai & Custom Gateways: Dynamic model discovery and proxy endpoint configuration stored in SQLite.
Planning Interactive Plan Editor

Presents file-level code modifications in side-by-side split diff editors. Before modifications are written to disk, developers can review changes and choose to accept or reject individual files. It also maps class dependency trees in inline visual formats.

Steering Taxonomy-Aware Steering

Classifies local development contexts (language, framework, scale) to tailor system prompts. Dynamically modifies search tool parameters to guide the model towards analyzing specific schema, route, and configuration files relative to the target codebase.

Context Token Budget Monitoring

Tracks active conversation context sizes in real time. Visual warning indicators flag potential context pollution as the token usage approaches the 200,000-token threshold, displaying detailed breakdowns of inputs, outputs, history, and active files.

Terminal Multi-Profile Shell Interface

Hosts terminal shell sessions directly within the UI, supporting PowerShell, CMD, Git Bash on Windows, and Zsh, Bash, and Sh on macOS/Linux. Terminal configuration handles process state cleanup on window unmount to prevent listener leakage.

Operator Manual

How to Use SmartCursorX

Step 1 Workspace Setup & Cloning

Launch the application and select a local development folder. Alternatively, use the integrated Git integration to input a remote GitHub repository URL. The application executes a secure, shell-escaped clone process and opens the directory.

Step 2 Provider Credentials Configuration

Open Settings (Ctrl + ,). Select your preferred API provider (e.g., Anthropic, OpenAI, or local Ollama). Input your API keys. Once saved, these keys are immediately encrypted via safeStorage at the OS-level before database storage.

Step 3 Prompting & Action Formulation

Enter your instructions in the AI Chat Panel. The model uses the local search, read, and list-directory capabilities to gather codebase context. All context assembly operations are restricted within the workspace path to block out-of-bounds reads.

Step 4 Code Planning Review

Once the AI generates a plan, the UI shows a blueprint roadmap. Check the permanently visible Implementation Trade-offs and Failure Modes & Consequences tabs to review design choices and potential risk profiles.

Step 5 Accepting or Rejecting Edits

Review file-level proposed edits side-by-side inside the Diff Editor. Click "Accept" on individual file changes to commit the modifications to disk, or "Reject" to discard them. You can click any text block inside the planner view to edit the markdown text directly.

Step 6 Compilation & Local Test Execution

Open the integrated terminal panel, select your shell profile, and run local test/compilation tasks (e.g., npm run test, npm run dev). Process lifecycles are monitored to prevent orphaned terminal sessions.
